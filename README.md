# -audio-social-mvp
 Мини-соцсеть для аудиосообщений. Запиши 20 секунд, кинь на стену, пусть мир услышит твой голос.  ## 🤔 Что это такое?  **Голосовая Стена** — это PWA-приложение, где пользователи записывают короткие аудиосообщения (до 20 секунд) и делятся ими с другими.  Главная фишка: на общей стене аудиосообщения появляются **рандомно**.
