# 🎙️ Голосовая Стена (рабочее название)

> Мини-соцсеть для аудиосообщений. Запиши 20 секунд, кинь на стену, пусть мир услышит твой голос.

## 🤔 Что это такое?

**Голосовая Стена** — это PWA-приложение, где пользователи записывают короткие аудиосообщения (до 20 секунд) и делятся ими с другими.

Главная фишка: на общей стене аудиосообщения появляются **рандомно**. Ты не выбираешь кого слушать — система сама подкидывает тебе голоса случайных людей. Этакий голосовой чат-рулетка, только асинхронный.

У каждого пользователя есть своя **комната** — личное пространство, где он может хранить свои записи и сам решать, открывать ли к ним доступ другим.

## ✨ Фичи (текущий MVP)

- 🎤 **Запись аудио** прямо в браузере (до 20 секунд)
- 🧱 **Общая стена** с рандомной подачей аудиосообщений
- 🏠 **Личная комната** для каждого пользователя с настройками приватности
- ❤️ **Реакции**: лайки на аудиосообщения
- 💬 **Текстовые комментарии** под аудиопостами
- 📡 **Оффлайн-режим**: запись сохраняется локально и автоматически отправляется при появлении интернета (таймаут ожидания — 6 часов)
- 🔒 **Премодерация**: все аудио перед публикацией на стену проходит ручную проверку

## 🛠️ Технологии

| Компонент | Технология |
|-----------|-----------|
| Фронтенд | HTML, CSS, Vanilla JavaScript |
| Бэкенд | [Supabase](https://supabase.com) (авторизация, БД, хранилище) |
| Хранилище аудио | Supabase Storage |
| Хостинг | [Vercel](https://vercel.com) |
| PWA | Service Worker, Web App Manifest |
| Аудио | MediaRecorder API |
